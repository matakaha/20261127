## 概要

| 項目 | 内容 |
|---|---|
| 機能名 | 注文キャンセルAPI |
| エンドポイント | `POST /orders/{orderId}/cancel` |
| 概要 | 顧客からの注文キャンセル要求を受け付け、キャンセル可否を判定し、必要に応じて返金処理を行う。 |
| 対象クラス | `CancelOrderService.java` |
| 作成日 | 2026-07-01 |
| 版数 | 1.3 |

## 機能仕様（要件一覧）

| 要件ID | 要件名 | 仕様内容 |
|---|---|---|
| REQ-001 | 注文の存在確認 | リクエストの注文IDに該当する注文が存在しない場合、エラー E-404 を返す。 |
| REQ-002 | 配送済み注文のキャンセル不可 | 注文ステータスが「配送済み（SHIPPED）」または「配達完了（DELIVERED）」の場合はキャンセル不可とし、エラー E-409 を返す。 |
| REQ-003 | キャンセル期限の判定 | キャンセル期限は注文確定から24時間以内とする。期限を超過した場合はエラー E-410 を返す。期限の例外は設けない。 |
| REQ-004 | 返金処理 | 支払済みの注文の場合、返金処理を実行する。返金額は「商品代金＋送料」の全額とする。 |
| REQ-005 | キャンセルの確定 | 注文ステータスを「キャンセル済み（CANCELLED）」に更新し、キャンセル操作ログ（操作日時・注文ID・操作者）を記録したうえで、受理応答（accepted）を返す。 |
| REQ-006 | 顧客への通知 | キャンセル受理後、顧客のメールアドレス宛にキャンセル完了メールを送信する。 |
| REQ-007 | キャンセル理由の受付 | リクエストのキャンセル理由コードは C01（顧客都合）/ C02（注文誤り）/ C03（配送遅延）/ C04（その他）のいずれかとする。これ以外のコードが指定された場合はエラー E-400 を返す。 |
| REQ-008 | 二重キャンセルの禁止 | すでに「キャンセル済み（CANCELLED）」の注文に対するキャンセル要求は、エラー E-409 を返す。 |
| REQ-009 | 引当在庫の解放 | キャンセル確定時、注文明細のすべての商品について引当在庫を解放する。 |

## 処理フロー

※ 図中の REQ-xxx は「機能仕様」シートの要件IDに対応する。

```text
開始
  ↓
理由コードは C01〜C04？（REQ-007）
  ├─ いいえ → E-400 を返して終了（理由コード不正 / REQ-007）
  └─ はい
       ↓
     注文IDで注文を取得
       ↓
     注文は存在する？（REQ-001）
       ├─ いいえ → E-404 を返して終了（注文が見つかりません / REQ-001）
       └─ はい
            ↓
          すでに CANCELLED？（REQ-008）
            ├─ はい → E-409 を返して終了（キャンセル済みの注文 / REQ-008）
            └─ いいえ
                 ↓
               ステータスは SHIPPED / DELIVERED？（REQ-002）
                 ├─ はい → E-409 を返して終了（配送済みのためキャンセル不可 / REQ-002）
                 └─ いいえ
                      ↓
                    注文確定から24時間以内？（REQ-003）
                      ├─ いいえ → E-410 を返して終了（キャンセル期限超過 / REQ-003）
                      └─ はい
                           ↓
                         支払済みの場合は返金処理を実行
                         （返金額：商品代金＋送料の全額 / REQ-004）
                           ↓
                         注文明細の引当在庫を解放（REQ-009）
                           ↓
                         ステータスを CANCELLED に更新し、
                         操作ログ（操作日時・注文ID・操作者）を記録（REQ-005）
                           ↓
                         キャンセル完了メールを顧客へ送信（REQ-006）
                           ↓
                         受理応答（accepted）を返す
                           ↓
                         終了
```

## エラーコード一覧

| エラーコード | HTTPステータス | 発生条件 | メッセージ |
|---|---:|---|---|
| E-400 | 400 | キャンセル理由コードが不正、またはリクエスト形式が不正 | リクエストが不正です |
| E-404 | 404 | 注文IDに該当する注文が存在しない | 注文が見つかりません |
| E-409 | 409 | 配送済み・配達完了の注文へのキャンセル要求 | 配送済みのためキャンセルできません |
| E-410 | 410 | キャンセル期限（注文確定から24時間）超過 | キャンセル期限を過ぎています |
| E-500 | 500 | 返金処理など内部処理の失敗 | システムエラーが発生しました |
